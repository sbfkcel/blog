# 微元智方（Vect²Add）信息科技有限公司

## 公司简介

微元智方信息科技有限公司是一家专注于AI技术应用研发的科技公司，致力于将前沿人工智能技术与传统行业深度融合，为产业升级和生产效率提升提供智能化解决方案。公司秉承"技术驱动创新，智能赋能未来"的理念，通过自主研发的AI产品矩阵，助力各行业实现数字化转型和智能化升级。

## 核心产品

### OpenInc. 智能体平台
企业级AI智能体开发与部署平台（openinc.ai），提供从模型训练到应用落地的全流程支持。平台支持多模态交互、工作流编排和大规模并发，帮助企业快速构建定制化AI智能体，降低AI应用门槛，提升业务自动化水平。

### o2ogame AI游戏平台
AI UGC 游戏平台（o2ogame.com），用户可以在平台上通过 AI 创作游戏，并享受来自其他玩家创作的游戏。平台将人工智能与游戏体验深度融合，通过 AI 辅助游戏创作、智能NPC、个性化推荐、游戏行为分析等能力，降低游戏创作门槛，为玩家提供更丰富、更智能的游戏体验，同时为游戏运营提供数据驱动的决策支持。

### 赚了么智能理财分析工具
基于机器学习和大数据分析的智能理财决策支持系统。工具通过AI算法分析市场趋势、评估投资风险、优化资产配置，为用户提供个性化的理财建议和投资策略，让AI赋能个人财富管理。
